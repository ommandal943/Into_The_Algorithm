t-SNE & UMAP: The House of Knowledge

💡

t-SNE & UMAP for Beginners (Explain Like I'm 5)

Imagine a 3D coiled spring or a complex high-dimensional globe. Linear methods like PCA fail because they flatten the coil onto itself. t-SNE & UMAP measure neighbor friendships in high dimensions, then simulate spring forces on a 2D canvas so close friends stay close while different clusters repel!

🤝 1. High-Dim Similarities ($p_{ij}$)

Converts distances into probability scores. Points close together have high similarity probabilities!

👻 2. The Crowding Problem Solution

Uses heavy-tailed Student-t distributions in 2D so points have enough room to spread out without crowding!

⚡ 3. Gradient Optimization

Iteratively pulls similar points together and pushes dissimilar points apart until 2D layout matches high-D topology!

🎯

1. High-Dim Probabilities ($p_{j|i}$)

Converts Euclidean distances into conditional probabilities under a Gaussian distribution:

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$
👻

2. Low-Dim Student-t Distribution ($q_{ij}$)

Uses a heavy-tailed Student-t distribution (1 degree of freedom) in low-dimensional space $y_i, y_j$:

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}$$
📉

3. Kullback-Leibler (KL) Loss

Minimizes the KL divergence between high-dim $p_{ij}$ and low-dim $q_{ij}$ similarity distributions:

$$\text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$
🌀

4. UMAP Fuzzy Simplicial Sets

UMAP models Riemannian manifold topology using Fuzzy Simplicial Sets and Cross-Entropy loss:

$$\mathcal{L}_{\text{UMAP}} = \sum_{i \neq j} \left[ p_{ij} \log \frac{p_{ij}}{q_{ij}} + (1 - p_{ij}) \log \frac{1 - p_{ij}}{1 - q_{ij}} \right]$$

💡 Interview & Production Guidelines

Q: Why can't cluster distances in t-SNE be interpreted globally?

t-SNE prioritizes local neighborhood structure over global distance preservation. The distance between distant clusters in a 2D t-SNE plot is mostly arbitrary.

Q: What is the main operational advantage of UMAP over t-SNE?

UMAP is significantly faster ($\mathcal{O}(N \log N)$ via Approximate Nearest Neighbors), preserves both local AND global topology, and allows projecting new unseen test points via `transform()`!

Q: What is Perplexity in t-SNE?

Perplexity sets the effective number of nearest neighbors for each point. Typical values range from 5 to 50.

Q: Computational Complexity Summary

Naive t-SNE: $\mathcal{O}(N^2)$ per iteration.
Barnes-Hut t-SNE: $\mathcal{O}(N \log N)$ complexity.
UMAP: $\mathcal{O}(N \log N)$ using Annoy/pynndescent indexing.
