01 — Deep Intuition & Mathematical Formulations

Decision Trees: The House of Knowledge

Master Decision Trees — from recursive binary partitioning and Gini/Entropy Impurity to Information Gain, Cost-Complexity Pruning, and Ensemble foundations.

💡

Decision Trees for Beginners (Explain Like I'm 5)

Imagine playing 20 Questions to guess an animal. You ask: "Does it have feathers?" → If Yes, "Can it fly?" → If No, it's a Penguin! A Decision Tree makes decisions in the exact same way: asking a chain of simple Yes/No questions about the data until it reaches a final answer!

🌱 Root & Internal Split Nodes

Questions that divide the data into two branches (e.g. "Is Age > 30?").

🍃 Leaf Nodes (Final Answers)

The bottom-most endpoints where no more questions are asked, giving the final prediction label or average value.

🧹 Impurity (Gini / Entropy)

Measures how mixed up a bucket is. Pure bucket (all same class) = 0 impurity. Split decisions pick questions that reduce impurity the most!

🌲

1. Recursive Space Partitioning

Decision trees partition feature space into non-overlapping axis-aligned hyper-rectangles using binary split decisions:

$$\text{Rule: } x_j \le t \quad \implies \quad R_1(j, t) \ \text{vs} \ R_2(j, t)$$

Greedily picks feature \(j\) and threshold \(t\) maximizing purity reduction at each step.

📊

2. Gini Impurity (CART)

Measures the probability of misclassifying a randomly chosen element from a node:

$$G(S) = 1 - \sum_{k=1}^{K} p_k^2$$

For binary classification with class probability \(p\), \(G(p) = 2p(1-p)\). Max impurity occurs at \(p=0.5\) (\(G=0.5\)); pure nodes have \(G=0\).

💡

3. Entropy & Information Gain

Entropy \(H(S)\) quantifies information disorder in node \(S\):

$$H(S) = -\sum_{k=1}^{K} p_k \log_2(p_k)$$
$$IG(S, A) = H(S) - \sum_{v \in \text{children}} \frac{|S_v|}{|S|} H(S_v)$$

C4.5 algorithm maximizes Information Gain (or Gain Ratio) to pick optimal feature splits.

📈

4. Variance Reduction (Regression)

For regression trees predicting continuous targets, split selection minimizes target variance:

$$\text{Var}(S) = \frac{1}{|S|} \sum_{i \in S} (y_i - \bar{y}_S)^2$$

Predicted value in leaf node \(R_m\) is the sample mean target \(\hat{c}_m = \text{avg}(y_i \in R_m)\).

⚡

5. Cost-Complexity Pruning

Unconstrained trees overfit by memoizing data. Cost-complexity pruning minimizes a cost function balancing tree size \(|T|\) and residual error:

$$R_\alpha(T) = R(T) + \alpha |T|$$

where \(\alpha \ge 0\) is the complexity parameter controlling tree pruning aggressiveness.

👑

6. Ensembles Foundation

Single trees have high variance. Combining multiple trees builds state-of-the-art ensembles (Random Forest & Gradient Boosting).
