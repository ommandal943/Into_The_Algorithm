02 · Linear Algebra

vectors and matrices are the data structures ML is built from
💡 PREREQUISITE NOTE: LINEAR ALGEBRA IN DEEP LEARNING
Every weight layer in PyTorch or TensorFlow is expressed as $y = \text{ReLU}(W^T X + b)$. Matrix multiplication allows modern GPUs to calculate millions of parameter activations concurrently in parallel.

03 · Calculus

how a model learns — the slope tells it which way to move
💡 PREREQUISITE NOTE: BACKPROPAGATION & THE CHAIN RULE
Deep neural networks depend on the chain rule $\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial h} \cdot \frac{\partial h}{\partial W_1}$ to propagate loss gradients backwards through hundreds of layers.

04 · Probability & Statistics

how to think about uncertainty, noise, and "is this signal real?"
💡 PREREQUISITE NOTE: LOSS FUNCTIONS ARE LIKELIHOODS
Minimizing Mean Squared Error (MSE) is mathematically identical to Maximum Likelihood Estimation (MLE) assuming Gaussian noise. Minimizing Binary Cross-Entropy (BCE) is MLE under a Bernoulli distribution!

Covariance & Correlation

Correlation is covariance rescaled to [-1, 1] — this is why you always standardize before comparing.

Bayes' Theorem & MLE

The single most important formula for reasoning under uncertainty — used explicitly in Naive Bayes, and implicitly everywhere else.

MLE is the principle behind fitting almost every model — "pick parameters that make the observed data most probable."

05 · Optimization

turning calculus + linear algebra + a loss function into a trained model
💡 PREREQUISITE NOTE: CONVEXITY VS NON-CONVEXITY
Linear and Logistic Regression feature convex loss surfaces with a single global minimum. Deep Neural Networks possess complex, non-convex loss surfaces with millions of local minima and saddle points!

🧪 Interactive Lab: Convex vs. Non-Convex Loss Landscapes

Toggle between Convex (Linear/Logistic Regression) and Non-Convex (Deep Neural Networks) to compare optimization landscapes.

The Loop Every ML Algorithm Runs

  • Define a loss function — MSE for regression, cross-entropy for classification
  • Compute the gradient of the loss w.r.t. parameters
  • Update parameters a small step opposite the gradient (learning rate α)
  • Repeat until convergence
