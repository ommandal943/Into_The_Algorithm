01 — Deep Intuition & Mathematical Formulations

Support Vector Machines: The House of Knowledge

Master Support Vector Machines — from primal/dual quadratic programming and maximal margins to Mercer kernels (RBF, Poly) and soft-margin $C$ regularization.

💡

Support Vector Machines for Beginners (Explain Like I'm 5)

Imagine separating red apples and green apples on a table. Instead of just drawing a thin line, SVM tries to build the WIDEST possible highway (the Maximum Margin) between the two groups so that there's a huge safety buffer on both sides!

🛣️ Maximum Margin Highway

SVM pushes the decision boundary as far away from both classes as possible, maximizing distance $M = 2/\|w\|$.

📌 Support Vectors

The key critical data points touching the edges of the highway. Deleting all other points doesn't change the line at all!

🔮 The Kernel Trick (3D Warp)

If points form concentric circles that can't be split by a straight line, RBF Kernel lifts points into 3D where a flat sheet can easily cut between them!

📐

1. Maximal Margin Geometry

SVM finds the separating decision boundary hyperplane \(w^T x + b = 0\) that maximizes the geometric distance (margin) to the nearest points of both classes:

$$\text{Margin } M = \frac{2}{\|w\|_2}$$

Maximizing \(M\) is equivalent to minimizing \(\frac{1}{2}\|w\|^2\).

🎯

2. Hard-Margin Primal Formulation

For linearly separable data, the constrained convex optimization problem is:

$$\min_{w, b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \ge 1 \quad \forall i$$

Points satisfying \(y_i(w^T x_i + b) = 1\) are Support Vectors.

⚖️

3. Soft-Margin & Slack Variables (C)

Real data has overlap. Slack variables \(\xi_i \ge 0\) allow controlled margin violations penalized by hyperparameter \(C\):

$$\min_{w, b, \xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i \quad \text{s.t.} \quad y_i(w^T x_i + b) \ge 1 - \xi_i$$

Large $C$ = Hard margin (small margin, zero misclassifications); Small $C$ = Soft margin (wider margin, allows errors).

🔄

4. Dual Problem & Lagrange Multipliers

Formulating the Dual via Lagrange multipliers \(\alpha_i \ge 0\) replaces weights with inner products:

$$\max_{\alpha} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

subject to \(0 \le \alpha_i \le C\) and \(\sum \alpha_i y_i = 0\). Non-zero \(\alpha_i > 0\) identify Support Vectors.

🪄

5. The Mercer Kernel Trick

Replaces dot product \(\langle x_i, x_j \rangle\) with kernel function \(K(x_i, x_j) = \phi(x_i) \cdot \phi(x_j)\) in high-dimensional feature space \(\mathcal{H}\):

$$K_{\text{RBF}}(x, x') = \exp\left(-\gamma \|x - x'\|^2\right)$$
$$K_{\text{Poly}}(x, x') = (x^T x' + c)^d$$
📊

6. Hyperparameter Tuning ($C$ vs $\gamma$)

Interactions between regularization $C$ and RBF kernel scale \(\gamma\):

$$\text{High } \gamma \implies \text{Small radius of influence } \implies \text{Complex, jagged boundary}$$
$$\text{Low } \gamma \implies \text{Broad radius of influence } \implies \text{Smooth decision boundary}$$
